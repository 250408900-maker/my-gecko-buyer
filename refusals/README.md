# refusals/

One file per refusal, written by the runner: the `field` that decided, what was `asked`
(from the pin) and what was `found` (in the prepared bytes, the menu, the signer or
verify), the `step` it happened at, and `signed: false` unless it was verify that refused.

Friday wants at least four distinct fields here from real devnet runs. Recorded runs never
write here; they go to `.recorded/`.
